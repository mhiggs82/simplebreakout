# Easy Breakouts: first test (about 15 minutes, 3 people)

**Who you need:** you (the host, on the Zoom desktop app) and two helpers, **Helper A** and **Helper B**. The helpers don't need the app.

**Before you start**
- Breakout rooms are switched on in your Zoom settings.
- You fully quit and reopened Zoom after changing the app's settings.
- Have this page open (or printed) to tick ✅ or ❌ as you go.

| # | Do this | You should see | ✅ / ❌ |
| - | ------- | -------------- | ------ |
| 1 | Start the meeting, then **Apps → Easy Breakouts**. | The "Easy Breakouts" header. The badge at the top says **Host**. | |
| 2 | Look at **Participants**. | Both helpers listed and ticked. It says they'll be put in rooms. | |
| 3 | **Quick start → Quick chat in pairs**, then press **Start**. | The task appears in the Zoom **chat**. The helpers are moved into a room (or get a Join message). A timer counts down. | |
| 4 | Ask the helpers: "Can you still see the chat message inside your room?" | Write down **yes** or **no**. We don't know this one yet. | |
| 5 | Press **Visit** next to their room. Then go back to the main room. | You move into the room, then back. | |
| 6 | Press **+ 2 min**, then **Pause**, then **Resume**. | The timer goes up 2 minutes, stops, then carries on. | |
| 7 | Press **End**. | Rooms close. "Welcome back to the main room." appears in chat. | |
| 8 | **Quick start → Parents like me**, then press **Ask everyone in chat to add it to their name**. | The instructions appear in chat. | |
| 9 | Helper A renames to **A - Netherlands, Amsterdam, 14–15**. Helper B renames to **B - Netherlands, Amsterdam, 16–17**. | In **Participants**, each shows their answers with "(from their Zoom name)". | |
| 10 | Set **Room size** to **2**, press **Preview rooms**, then **Make rooms**. | "Moving people…", then "2 people are in 1 rooms" (yes, it says "rooms"). The room is named something like "Netherlands · Amsterdam". | |
| 11 | While rooms are open, ask a 4th person to join (or a helper to leave and rejoin). | "1 person isn't in a room yet · Put them in rooms". Press it. They're moved into the room. | |
| 12 | Press **Close rooms**. | Everyone comes back to the main meeting. | |
| 13 | In **Participants**, press **Untick everyone**, then tick just one helper. | **Make rooms** is greyed out, because rooms need at least 2 people. | |

## Write down
- How long "Moving people" took in step 10: ________ seconds
- Anything confusing, or words you'd change: ____________________
- Any red error text: take a photo or screenshot.

## If something goes wrong
| Problem | Try this |
| --- | --- |
| No task in the chat | In the Zoom Marketplace, check `sendMessageToChat` is on (on the **Development** tab too), then fully restart Zoom. For Pairs and Rotate, also check **More options → Post the task in Zoom chat** is on. |
| Name answers don't show | The name needs a dash (with spaces) or brackets before the answers, e.g. "A - Netherlands, Amsterdam, 14–15". The spelling must match the options. |
| "Rooms are still open" | Close them from Zoom's own **Breakout Rooms** button, then try again. |
| Helpers aren't moved | Check **Move people automatically** is on (under **Room settings**, or **More options** for Pairs). Otherwise they get a Join message and need to click it. |
| The badge says "Attendee" | You need to be the host or co-host. |

When you're done, send the ✅/❌ column and your notes, and we'll fix anything that didn't work.
